# First-run Paper & Pencil suggestion

Reference commit `5c8f8f0595f31a0d6532d660cad73135e8223cc2` adds this main-product step. Companion Continue opens Paper & Pencil only when both its account-wide acknowledgment and the existing setup acknowledgment are absent. Existing setup-complete accounts skip it. Understood, tapping the backdrop and the accessibility escape action acknowledge the suggestion and continue to setup or placement using the latest account/language state. Placement retains its original mounted-session guard. No writing canvas is implied by this informational screen.

The SwiftUI view uses the original copy resolver for eleven source locales, the original SVG illustration and emblem, and separate native pencil/sparkle layers. WebKit serializes and rasterizes those authored layers at 3× on the QA iPhone; the app does not load the web modal at runtime. Motion uses the source origins, delays, durations and cubic easing, pauses when inactive and respects Reduce Motion. The delayed right sparkle stays opaque before its animation begins. Source SVGs, screenshot geometry, sampled animation matrices and asset hashes are retained in [the source evidence](reference/paper-pencil/art-manifest.json). The original callback notes/timing are rendered as a short bundled sine sound; its PCM envelope approximates Tone.js rather than claiming acoustic identity. Sound preference and volume are respected, with native light haptics when sounds are enabled.

The acknowledgment writes only `paperPencilModalShown: true` (or `gettingStartedModalShown: true`) and `updatedAt` to the canonical owner document. It first saves locally; failed cloud writes retain the local flag for ordinary progress-sync retry. It does not call the general persistence path, prepare or claim a plate, award XP, or flush unrelated pending work. Imports and concurrent-save rebases preserve true acknowledgments against stale false/missing flags. Old accounts decode without the optional field. Identity guards fence late failures from a replacement account. No backend/rules deployment is required.

At 402×874, the original light modal measures 361.797×579.703 points; Arabic dark measures 361.797×561.703. Its global CSS pseudo-element draws a three-point frame even though the element's computed border is zero. The SwiftUI shell includes that frame and the original shared backdrop through the Paper → setup → placement handoff. Header gradient direction stays physical left-to-right in RTL. Dynamic type and small-screen scrolling remain native adaptations.

## Reproduction

Run the target-owned read-only preview with `node scripts/start-reference-preview.mjs`, then opt into `PaperPencilReferenceTests` on the separate QA simulator. It renders the actual source component with sounds disabled and no learner identity/provider I/O, records the SVG layers, motion matrices and geometry, and captures static native comparisons. Export attachments from its terminal xcresult and run `node scripts/import-paper-pencil-art.mjs <attachments-directory>`. `node scripts/export-paper-pencil.mjs` regenerates copy, motion descriptors and the action sound; `node scripts/export-first-run-policy.mjs` executes the source decision callbacks for 288 flag/placement/session combinations.

Simulator artwork and state tests do not establish physical haptic feel, speaker output, VoiceOver operation, all text-size/localization combinations or complete product/design parity. Modal entry/exit motion and broader screen comparisons remain part of the active parity audit.
