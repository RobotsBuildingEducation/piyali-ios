# Paper & Pencil entry and setup

The current reference starts with Paper & Pencil closed. After onboarding, the companion’s Continue action opens it when the account-wide paper acknowledgment is missing. Understood records the acknowledgment and continues to installation and key guidance or to placement. The [first-run reconciliation](REF_01_PROGRESS.md) documents the current callbacks and supersedes the older mount-time modal behavior.

The previous animated SVG notebook, floating pencil, sparkles and header emblem are no longer rendered. SwiftUI now uses the exact `paper_pencil_manga.webp` bytes from the read-only reference (960×448), the original copy resolver for eleven locales, the icon-free teal header, source responsive artwork limits, small-phone body scrolling, rounded frame and shared backdrop. The image is decorative for accessibility. Original source line boxes are measured in iPhone WebKit; its fractional CSS line heights round down, and global modal CSS supplies extra bottom padding. Landscape uses the source larger header/body/button layout. Native does not embed the web modal at runtime.

Understood closes the modal. Backdrop taps, body taps and accessibility escape leave it open. The covered Focus controls are hidden from accessibility. The original deferred action notes and timing are rendered as bundled sine PCM with the source sound preference and volume. The envelope approximates Tone.js.

Product acknowledgment still writes only `paperPencilModalShown: true` (or `gettingStartedModalShown: true`) and `updatedAt` to the canonical owner document. Local-first flags, monotonic import/rebase, stale-account fencing and retry remain unchanged. This does not award XP or flush unrelated earned work. No backend/rules deployment is needed.

## Reproduction and evidence

Run `node scripts/export-paper-pencil-entry.mjs` to execute the original App initializer/onboarding-close/product callbacks for all eight paper/setup/placement flag combinations, with only public state, persistence and paint adapters. Their source hashes and scope are retained in `docs/reference/paper-pencil-entry-manifest.json`.

It renders the actual original modal at 320×568, 375×667, 402×874 and 874×402 in English/light and Arabic/dark, checks the absent SVG/icon, body-click behavior and original Understood callback, and compares native panel dimensions. Export attachments only after the result becomes terminal, then run `node scripts/import-paper-pencil-art.mjs <attachments-directory> <result-name>`. The current 32 image/metric records and asset hash are in `docs/reference/paper-pencil-manga-captures.json`.
