# Home companion panel

This pass compares the original PlatePetPanel directly with the native home companion at 375- and 402-point phone widths. The earlier Swift version used SF Symbols for the heart/chart/gamepad, squircle outlines where iPhone WebKit renders circular corners, a generic two-row title fallback that lost the separator, and guessed badge colors. It also sized the level XP value as 12 points rather than the source's 11.

The native panel now uses the original FiHeart, MdShowChart, TbDeviceGamepad3 and edit glyphs, the actual rounded 28-point panel/20-point canvas and capsule buttons, the source badge palette, value sizes and dark theme colors. The drawing occupies the canvas's 94-point inner area inside its 96-point border box. The three title flex items wrap independently, preserving the indivisible separator/level group. SwiftUI mirrors placement in Arabic; its mixed Arabic/Latin meter label receives explicit paragraph direction to match the source's dir attribute.

The dark web theme uses its own data-theme-mode selector without changing Chakra's color-mode selector. Consequently the original badge still resolves Chakra's light-mode 100/800 color tokens in the dark panel. The source theme also remaps pink tokens to the default orange palette, making the dark heart orange. The exporter reads the original stage copy/palettes, Chakra badge variant, app gray override and original React icon. The source manifest now includes the theme store and package lock alongside the existing component/drawing/theme hashes.

Panel bars follow the source's 0.8-second cubic-bezier [0.22, 1, 0.36, 1] fill and one-point inner border, with immediate final fill for reduced motion. A clock evaluates the fill independently of implicit first-layout transactions. Updates start from the currently visible fill, and displayed daily XP may exceed 100% while its bar caps at 100%. A nonpositive goal displays 0%, matching the original panel. Other bars retain their existing default fill behavior.

## Comparison scope

The target-owned reference companion wrapper supplies anonymous public properties to the unmodified source panel. It does not sign in, write a learner document or call a remote provider/relay. Source and Swift render the same health, language XP, daily XP, level and names. Four pairs cover English/light with 80% health/56 XP at 402 points, Arabic/dark with 49% health/240 XP/250% daily progress at 402 points, and long English/Arabic names at 375 points with 24% and 0% health. Pet animation phases remain time-dependent, so pixel-identical drawings are not claimed. Source and native captures wait beyond the initial fill duration.

The canonical main-product panel remains SwiftUI with native drawing and interaction. No web panel is embedded in the iPhone app. The broader home/companion lifecycle and blueprint work are documented in [Today’s Focus](TODAY_FOCUS.md), [quests](COMPANION_QUESTS.md), [customization](COMPANION_CUSTOMIZATION.md), [unlocks](COMPANION_UNLOCKS.md), [save feedback](COMPANION_SAVE_FEEDBACK.md) and [Activity](XP_ACTIVITY.md).

## Limits

This is a scoped phone-panel correction, not full home or product parity. Fine text baselines/rasterization, all ten languages, other widths/text sizes, modal and recording motion, physical-device rendering and accessibility still need broader comparison. The initial companion message and wider task/Score layouts retain their separately documented boundaries. The reference checkout remains read-only; no backend or rules deployment is required.
