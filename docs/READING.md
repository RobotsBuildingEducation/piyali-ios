# Native reading

Reading from lessons, Practice and Getting Started opens a native passage screen. Gemini generates single-author target-language prose, three support-language takeaways and a grounded text, fill-in or four-choice question. Cloudflare Responses remains the authenticated fallback. Listening uses iOS speech synthesis; translation and saving to private notes are available.

The bundled curriculum already contains authored reading subjects and required document scopes. Native selection follows the reference's CEFR format eligibility, authored subject order and least-recent format/angle/structure rotation. Required menus, schedules and other documents take precedence over random formats. The tutorial asks for the source's four introductory meanings, including Piyali's name. Generation retries up to three times after missing fields, invalid questions, dialogue scripts, reaction chains, wrong target scripts or recent-passage repeats. Quality checks preserve document headings rather than stripping them into ordinary paragraphs.

A passage latches a random 5–8 XP reward. A correct comprehension answer grants it once and updates the quoted performance score. Misses allow retries, capture companion memory and have no XP or score penalty. Read-aloud review grants the same reward once regardless of word matching and does not update the performance score. Its feedback compares an actual speech-recognition transcript with passage words; it makes no phonetic pronunciation claim. The two review methods share one Firestore receipt, including concurrent submissions from different devices. Proof records are private to the learner.

Drafts retain the passage, question, selected answer, feedback, translation and shared award across relaunches. Current drafts are bounded to three target languages/96 KB; recent passage history is bounded to thirty per target and 96 KB overall. Saving a new passage keeps prior diversity history. Online work is cancelled or discarded after account/context changes.

Verification includes source-generated fixtures (67 quality cases, 84 format choices, 48 question-normalization cases and 11 XP boundary cases), reward/score/draft tests, an emulator test racing comprehension against speech, private-proof security checks, and a simulator flow covering a wrong answer, retry, relaunch and a single persisted reward. The debug Spanish fixture is newly authored test content, enabled only with isolated offline test identity settings. It never grants subscription access.
