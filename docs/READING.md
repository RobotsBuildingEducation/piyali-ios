# Native reading

Reading from lessons, Practice and Getting Started opens a native passage screen. Gemini generates single-author target-language prose, three support-language takeaways and a grounded text, fill-in or four-choice question. Cloudflare Responses remains the authenticated fallback. Listening now uses the [original narration session and native receive-only RTC](READING_STORY_AUDIO.md), with source Read all/Stop controls and sentence selection. Aligned translation is available.

The bundled curriculum already contains authored reading subjects and required document scopes. Native selection follows the reference's CEFR format eligibility, authored subject order and least-recent format/angle/structure rotation. Required menus, schedules and other documents take precedence over random formats. The tutorial asks for the source's four introductory meanings, including Piyali's name. Generation retries up to three times after missing fields, invalid questions, dialogue scripts, reaction chains, wrong target scripts or recent-passage repeats. Quality checks preserve document headings rather than stripping them into ordinary paragraphs.

A passage latches a random 5–8 XP reward. A correct comprehension answer grants it once and updates the quoted performance score. Misses allow retries, capture companion memory and have no XP or score penalty. Read-aloud review grants the same reward once regardless of the model's scores and does not update the performance score. It uses the original transcript-based model prompt for accuracy, completeness, pronunciation, fluency, confidence and comprehension. These are estimates from recognized words, not phonetic measurements from recorded audio. The two review methods share one Firestore receipt, including concurrent submissions from different devices. Proof records are private to the learner.

Drafts retain the passage, question, selected answer, feedback, translation and shared award across relaunches. Current drafts are bounded to three target languages/96 KB; recent passage history is bounded to thirty per target and 96 KB overall. Saving a new passage keeps prior diversity history. Online work is cancelled or discarded after account/context changes.

Verification includes source-generated fixtures (67 quality cases, 84 format choices, 48 question-normalization cases and 11 XP boundary cases), reward/score/draft tests, an emulator test racing comprehension against speech, private-proof security checks, and a simulator flow covering a wrong answer, retry, relaunch and a single persisted reward. The debug Spanish fixture is newly authored test content, enabled only with isolated offline test identity settings. It never grants subscription access.

## Continuous capture correction

Reading now has a dedicated native recorder. The original `readingSpeechRecorder.js` policy runs in Swift: complete interim snapshots replace earlier partials; completed utterances are archived once and joined; deliberate repeated phrases in different utterances remain. Normal ends restart after 100 ms with words or 300 ms without them. Stop stops input, accepts final words for up to 1.5 seconds, and then recovers even if the recognizer never ends. Three empty sessions or repeated network failures stop with the original error category, and the whole recording stops at three minutes. Permission, stale session and clock callbacks cannot reopen cancelled capture.

Apple's adapter stops input and calls [`SFSpeechRecognitionTask.finish()`](https://developer.apple.com/documentation/speech/sfspeechrecognitiontask) for a deliberate Stop; Cancel immediately invalidates the session and cancels its task. That distinction preserves buffered recognition instead of discarding it. Apple task errors use the SDK's documented error-domain table; a speech-service failure is not presented as an Internet outage. Displayed errors use the original `speechPracticeFeedback.js` title/description keys. Temporary inactive permission dialogs preserve the request, while backgrounding, leaving the view, losing access or replacing/completing the active passage stops capture. Existing text in the same owned draft is saved without granting XP; model review still requires explicit submission after finalization. Actions from inactive or finalizing controls cannot begin grading or reopen capture.

Read-aloud transcripts now retain up to 16 KB of valid UTF-8 instead of truncating at 4,000 characters. The same text reaches the model prompt, private draft and receipt. Question answers keep their previous limit. Stopped drafts and closing words in longer paragraphs survive relaunch/sync; invalid UTF-8 tails are never introduced by the byte bound.

`scripts/export-reading-capture-fixtures.mjs` executes the unmodified reference recorder with synthetic recognition events and a virtual clock. Native Core compares 15 complete event/clock journeys plus seven error presentations, including duplicate ends, old callbacks, deliberate repeats, late final words, missing ends, no-speech recovery, bounded network retries, restart cancellation and the three-minute limit. The iPhone adapter/controller also has six native checks for buffered completion, real cutoff/restart timers, permission replacement/cancellation, late callbacks and error classification. These checks and synthetic simulator capture do not verify the physical microphone, Bluetooth routes or Apple recognition service behavior on a device.
