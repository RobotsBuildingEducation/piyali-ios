# Tutor live replies and translated phrases

The native Tutor previously showed translated text without the web app's phrase cards. It highlighted only the first occurrence of each phrase and could retain a previous translation after translations were disabled in the imported learner settings. The shared native reply now renders the original visible-pair filter, overlap order, repeated phrase tokens, eight-card limit, translated text and phrase selection. The same component renders assistant messages in private history. The normal voice surface also restores the source's localized Listening/Speaking/Thinking label below the orb, using the original status helper; muted/paused badges retain their separate source behavior. Translation visibility applies to existing replies and history without deleting their saved text/pairs.

SwiftUI owns rendering, wrapping, selection, accessibility and replay actions. `tutor-reply-policy.js` contains only the original pure phrase helpers, transpiled with the reference's existing esbuild dependency and a neutral element-data adapter. It neither mounts React nor performs I/O. The actual source `AlignedBubble` executes separately in WebKit for comparison. Both use the original theme, CSS, bidi helpers and public response data. Arabic comparisons use the real document-language/right-to-left context. The source's inactive inline-feedback branch is excluded from this main-product comparison: `inlineFeedbackKind` initializes to null without a setter in the inspected component.

The native reply uses measured iPhone WebKit line boxes, wrapping cards and original light/dark palette and panel styles. It preserves the existing replay service and audio duck/restore callbacks. Recorded-clip replay and broader narration preparation retain their separate existing limitations. Original source token grouping is preserved, including repeated/overlapping phrases and the source's selection grouping; the native view adds an accessible selected trait.
