# Companion customization

Home and Goal Manager now use the original two-column, six-companion picker with the source’s level gates, localized labels, health-dependent pixel artwork, selected treatment and locked opacity. The centered 370-point dialog at a 402-point viewport has the original 48-point circular corners and inset frame. Its Home variant is 628 points tall; Goal uses the source’s additional header/body spacing for 668 points. Cancel, the capsule Save button and its teal press edge follow the source. Arabic retains the source portal’s ordering with translated labels. The original edit and lock SVG paths are bundled assets.

Opening starts a fresh name/style draft. Cancel or outside dismissal discards it; Save or Return commits it and closes. Names use the original trim rules and 24 UTF-16-unit limit. An empty name restores the localized default. Locked or invalid types fall back to Ghost; existing uppercase type values normalize like the web. The Goal editor also resets from changed live values, matching its controlled source modal. Its native presentation covers the Goal Manager while keeping that manager open underneath.

Customization now has its own partial settings receipt containing only `dailyGoalPetName` and `dailyGoalPetType`. It does not mark the entire preference form dirty, grant XP, change health or publish a Nostr record. Canonical restore replays pending local changes, and in-flight acknowledgments preserve a newer draft save. A repeated receipt cannot undo a later web customization. Unrelated language, voice, daily goal, unknown typed fields and paid membership fields remain intact. Existing snapshots with a pending whole-form write migrate their companion intent once; the deterministic migration receipt also survives a lost acknowledgment before a new local snapshot is written.
