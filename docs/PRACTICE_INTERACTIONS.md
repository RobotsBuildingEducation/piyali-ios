# Native question interaction checkpoint

Grammar and vocabulary now open native typed questions rather than the former generic `Exercise` form. The eight standard formats and nine Delight variants use the original prompt policies and JSON contracts. Generated answer keys remain separate from the displayed prompt. Ordered word banks retain duplicate token positions; matching uses complete one-to-one assignments; listening and translation keep their source/answer languages distinct. Speaking and lesson flashcards accept native speech input. Lesson flashcards can flip, play their answer and review a deck without XP for revealing or reviewing. Correct graded answers automatically collect their card.

Wrong answers leave the question available for another attempt. Correct answers grant the format's own reward once, using lesson metadata for the lesson-owned counter. Normal choices remain independent practice; a delivered assistant hint marks supported practice. Private snapshots retain the question, bank positions, response, clue count, result and collected cards. Ordinary curriculum entry starts fresh source content while retaining earned lesson XP; introduction and quiz use their own session rules. See [Question actions](QUESTION_ACTIONS.md). Account/language changes and view dismissal invalidate pending provider results and stop audio.

Semantic judges accept contextual alternatives through the original judge instructions. Natural or Weird remains deterministic; grammar matching uses its answer map. Flashcard judging retains the 4–7 XP scale. Sentence Detective uses its dedicated source generator. Morphology Forge runs the source's reference-word/morpheme preflight before presentation. Invalid primary drafts switch to an independent Responses attempt. The source's question-specific translations, labels and placeholders are exported, alongside its question colors and system product typography.

Validation includes:

- Core checks for phased JSON, malformed drafts, word positions/directions, incomplete maps, saved questions, retry/reward deduplication, assistance and lesson scope, collection without XP, and source policy output across 136 fixtures.
- iOS judge-boundary checks for vocabulary fill's actual `sentence` contract, alternate translations, binary judgments and flashcard rewards.
- Real iOS provider runs producing usable contracts for all 17 grammar formats in Spanish, including Morphology Forge preflight and Responses fallback. A separate check covers Japanese vocabulary matching and semantic judging. This does not prove every language or every provider draft succeeds.
- Isolated simulator journeys for wrong-answer retry/relaunch, duplicate word-bank selection/removal/resume, and lesson-card collection/review. UI-test question providers are compiled only in Debug and require explicit offline and isolated-identity flags.

Ordinary curriculum lessons now use the source preview and a first session controller with activity handoffs and a completion presentation; [the actual 80-XP lesson journey](CURRICULUM_SESSION.md) is checked. The introduction and lesson realtime now have their own inline sequence/goal renderer. Source curriculum context is supplied to grammar/vocabulary and realtime; grammar matching applies the original pair-grounding check. The five advanced detective/choice/sorting/forge bodies now have source layouts and native gesture controls; see [Exercise bodies](EXERCISE_BODIES.md). The three writing bodies, their five beta keyboards and transcript auto-submission now have their own native implementation; see [Writing exercises](WRITING_EXERCISES.md). Fill, MC, MA and Match now use their source bodies, including native inline slots and matching gestures; see [Standard exercises](STANDARD_EXERCISES.md). Translate and Repeat now use source question cards, native ordered banks, saved token positions and original assistance; see [Word-bank exercises](WORD_BANK_EXERCISES.md). Speaking and lesson flashcards now restore source bodies, automatic transcript submission and collection, explicit retry and cyclic deck navigation; see [Oral exercises](ORAL_EXERCISES.md). Remaining work includes broader background preparation/streaming, assessment/context integration for other engines, other legacy help prompts, broader virtual keyboard integration, exact question audio and physical-device checks. Other legacy exercise routes and feature panels still need their own parity work. These checks are a correction checkpoint, not a claim of complete product parity.

Grammar/vocabulary and curriculum realtime now save source difficulty quotes and apply them to progress; see [the assessment checkpoint](QUESTION_WORTH.md).
