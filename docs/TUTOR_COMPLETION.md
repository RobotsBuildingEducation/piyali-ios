# Tutor completion, review and return to the path

The source's game completion callback waits for the canonical Tutor reward, removes the game, and reopens the Tutor path behind its lesson-completion modal. Continue opens the completed-agenda review. Closing that review releases a queued daily-goal celebration, then the once-per-account scholarship flow. Completed-lesson game practice returns to the path without another Tutor bonus or completion/review sequence.

The initial native handoff closed the path to reveal completion on the voice surface. Its Continue handler also released the daily-goal celebration before review, reversing the source sequence. Tutor's path now uses a scoped presentation in the product root, below the shared reward layers. Its original controller remains mounted. The completion/review flow is shared with the voice surface, and earned-practice ownership remains active until review closes. The released daily-goal reward can appear over the returned path. Scholarships and task acknowledgments retain their source quiet-window gate until the path closes. Account/target replacement and leaving Tutor clear the owned path; the regular simulator is excluded from all QA fixtures.

A completed run is marked retired only after its Tutor completion receipt is acknowledged, or after finishing completed-lesson practice. It earns no skill-tree reward. Failed saves retain the current game and the same completion intent. Subsequent practice creates a fresh game from the existing preparation cache/authored deck instead of reopening the old recap, while canonical Tutor completion remains once-only. A restored game with an unacknowledged bonus reuses that durable receipt; it remains available for retry. Older completed/unretired runs become fresh practice only after the canonical bonus is acknowledged. Selecting completed practice preserves the local selected-lesson field without inventing another Tutor start or XP award.
