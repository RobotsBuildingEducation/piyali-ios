# Companion unlock celebrations

The native app now uses the web product’s level-crossing companion sequence. Alien, Robot, Slime, Dog and Axolotl unlock at levels 2, 5, 10, 20 and 40. Earned positive XP in the active practice language queues newly crossed thresholds in that order. Ordinary local restore is a baseline; ongoing cloud XP changes can enqueue an actual crossing. Already celebrated flags arriving after the queue was created are checked again immediately before presentation.

The queue reproduces the original quiet-window timers: a 90 ms initial check for lesson/repair lesson/Speak, 900 ms minimum when an expected modal has not appeared, and a 120 ms minimum for ordinary crossings. A visible or pending lesson, daily-goal, scholarship or quest dialog delays presentation; polling an actual blocker uses 90 ms intervals and releasing it bypasses the minimum quiet delay. Local UIKit sheets are also checked before opening. Account changes discard visible and queued work, and stale action callbacks cannot equip another account’s companion. Native modal ownership also holds newly arriving reward dialogs until the companion closes.

The celebration uses the source’s three-stop cyan gradient, 48-point circular corners, inset frame, title/subtitle, original pixel companions, white preview panel, happy badge, wave health bar, raised Equip button and Keep current action. At the 402-point reference viewport, the English Alien dialog is approximately 362 × 439 points. Ten supported locales use the actual original copy, including its German fallback. Arabic follows the source portal’s left-to-right panel and paragraph ordering, including punctuation. The dark heart icon follows the source’s default orange accent remapping. The name captured when queued is the localized species name. Equip preserves the learner’s current custom name and saves only the selected type; Keep current leaves both fields intact. Outside taps cannot dismiss this celebration.

The preview shows 100% health as the web modal does, without changing actual health or granting XP. The acknowledgment is saved at presentation, before either choice, through both the account-scoped local preference and a durable partial settings receipt for `companionUnlocksCelebrated`. Map writes merge across devices; empty maps, false flags and unknown incoming names cannot clear an existing acknowledgment. Existing unknown stored entries retain their values. The sparkle sound is a bundled sine PCM rendering of the original pitches, timing, gain and envelope, subject to the learner’s sound setting and volume. It does not change the live microphone session category.
