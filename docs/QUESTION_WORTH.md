# Generated question difficulty and progress

Grammar/vocabulary now assess the difficulty of the actual prepared question using the original prompt and strict 0–100 parser. The evidence object matches the web activity, including its actual shuffled word bank, choices, hints and relevant answer references. Delight variants use their source assessment mode. Curriculum realtime also assesses generated goals; introductory greeting goals keep the source's CEFR fallback.

The model estimates difficulty. The app calculates a saved v4 quote with the original fixed policy; that estimate never becomes an XP or Score award directly. Answers apply the saved independent/prompted gain or missed-answer loss. The same quote travels in the private question snapshot and transactional assessment event. Local and Firebase updates use the same price, record the assessed evidence level, and retain source recent-results/weak-concept history. Assessment itself grants zero XP. Failed difficulty requests keep an explicitly marked CEFR fallback, and older saved questions retain their existing fallback behavior.

Additional revealed clues count as assistance. A repeated unchanged incorrect answer cannot apply another assessment; changing the answer and succeeding still works. Completed question and event guards prevent another reward. Account/language/question changes cancel stale preparation before it can save a quote or answer.

Verification includes 672 source/native outcome comparisons spanning six starting ratings, seven curriculum levels, four assessment/fallback cases, assisted/independent answers and both outcomes. Snapshot, malformed quote/parser, retry and actual-bank checks cover persistence and boundaries. An opt-in live provider check generated actual My Family vocabulary/matching and obtained valid model difficulty assessments. Dedicated demo-project Firestore tests exercised concurrent success/miss sync and event retries without XP, alongside the lesson-counter concurrency regression. The full core suite passed 184 checks.

This is scoped to grammar/vocabulary and curriculum realtime. Broader legacy-mode assessment, initial legacy-rating estimates, the prepared-question pipeline and full product parity still need audit. The difficulty assessor currently shares the native configured text-provider/fallback path. Physical audio and release setup remain separate requirements.

The latest iPhone regression run passed the three judge checks, answer retry/relaunch (36.6s), and complete 80-XP lesson/bonus/unlock/relaunch journey (105.6s). These use isolated offline interaction data; actual generated difficulty and Firebase concurrency are covered by their separate live/emulator checks.
