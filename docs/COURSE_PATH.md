# Course path parity checkpoint

The ordinary Lessons path now uses the reference's CEFR badge/name/description, gated previous/next buttons, language XP and completion header, colored unit headers with completion counts, 90-point lesson circles, original lesson-specific SVG icons, lesson-earned-XP rings and curved sequential connectors. The separate starting-level control and native navigation title have been removed from this surface; placement remains available through the existing product settings.

The introduction is part of its actual unit. Completed nodes remain reviewable; resumable lessons remain accessible. Choosing “completely new” retains the introduction and sequential beginner gates. The former placement helper incorrectly allowed Pre-A1 to unlock every Pre-A1 node. It now follows `isContentUnlockedByPlacement`: placement must be above Pre-A1 and at or above the requested content level. Saved completion and in-progress records still take precedence. No XP or completion is added by placement.

`export-course-path.mjs` reads the reference without changing it. It bundles the original title/icon, node appearance, CEFR navigation, completion and placement helpers for JavaScriptCore, with 309 source-executed cases and 185 original icon PNGs. The native renderer reads unit color metadata from the existing source-derived `lesson-appearance` bundle. `course-path-manifest.json` records source hashes. The public screenshot fixture uses original `LessonNode`, `UnitSection`, `CEFRLevelNavigator` and `CourseProgressHeader` components, extracted with their original helpers/imports. Public starter content comes from the existing content bundles with their original appearance metadata; fixture progress is explicit. It does not run the reference root, connect an account, award progress or call a provider.

The native path keeps the existing lesson-preview → playable preparation → staged game handoff. Activity-specific RPG UI tests now use the actual A1 self-report and navigate back to A0, instead of depending on the old beginner unlock bug.

Verification and captures are recorded in [VALIDATION](VALIDATION.md). The paired screen states cover beginner and 6-XP resumable work in English/light and Arabic/dark at the top and within the first regular unit. Native product journeys cover new learner gating, higher placement access and relaunch, plus the playable course-game handoff. Broader imported-progress combinations, every level/locale/device size, mixed UI/support preferences, the explicit scroll-to-latest action, remaining title/shadow/press calibration, viewport motion/performance and physical accessibility remain open. This checkpoint does not establish full application parity.

Restart the read-only preview after editing its fixture plugins: they are Node startup modules. The screen check uses nonpersistent WebKit storage and asserts the requested theme CSS before taking captures. An earlier comparison reused the old plugin module; its English theme captures are not visual evidence. The final source check also mounts the native path inside its actual NavigationStack with the comparison-only safe area removed.
