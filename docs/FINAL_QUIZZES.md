# Typed curriculum final quizzes

Path quizzes now mount the same typed grammar renderer as ordinary lessons. The original option selector supplies sixteen formats per deck without flashcards, fixes the authored CEFR level, and saves the plan with the run so relaunches do not reshuffle consumed formats. Generation uses the original prompt policies, authored curriculum context, matching guard, normalization and semantic judges. Generated difficulty is quoted and saved with each question.

The source rules remain eight correct within ten questions, or ten within twelve for advanced quizzes. Each item accepts one attempt, including a wrong answer. Its inputs lock after judging; Next advances after either result. Skip, recheck and answer-revealing assistance are absent during the attempt. The original localized result copy, blue/red progress segments, retry and Back to Lessons controls replace the older generic exercise quiz. Early failure, early passing, an unanswered item, counted answers and the planned options survive relaunch. A new attempt fences late answers from its predecessor. Completed quizzes can be reviewed in a fresh round.

Questions earn zero XP and produce one quoted assessment through the existing transaction outbox. Passing retains the native once-only authored lesson reward and unlock gate. **Completion integration difference:** the reference's quiz exit currently calls `handleReturnToSkillTree`, which clears the active lesson without an explicit quiz-pass completion claim. Native successful exit retains its existing completion integration so a quiz does not strand the course. This requires resolution during the broader course audit; it is not evidence of exact source completion wiring.

Private runs/pass records use the native learner snapshot. Concurrent draft edits remain last writer wins; assessment events and completion receipts use their transaction protections. Browser localStorage drafts are not imported into the separate Piyali backend. Old generic-question snapshots remain decodable; an unanswered legacy draft is replaced when the typed plan is first installed, while counted results remain.
