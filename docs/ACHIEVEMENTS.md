# Native achievement transcript

The main product’s achievement collection is a centered modal with Piyali and Robots Building Education tabs, completed/locked card grids, source series order, localized counts and a fixed collection progress footer. Its mobile inset, Close position and footer padding follow the actual global source theme overrides; paragraph labels use explicit document direction and greedy wrapping. Its complete catalog contains 104 permanent awards: 75 Piyali, 28 Robots Building Education and one shared final award, giving tab totals of 76 and 29. Displaying cross-platform awards does not add external course routes to the iPhone app.

`export-achievement-transcript.mjs` executes the original catalog, localization and grouping functions. It exports all ten authored locales, source theme dictionaries, number formatting, twenty character expressions/patterns and the original twenty-one reaction policies. Native completion display uses the existing validated saved records, with the source’s collected/locked partition. It does not award from XP, placement or displayed counters. Existing Firebase progress verification, permanent document IDs and Nostr ownership/signature checks remain responsible for awards.

Today’s Focus opens the native collection directly. The underlying menu is isolated while the modal is shown. Tabs, scrolling, Close, outside dismissal and the fixed footer remain native SwiftUI controls. Opening restores signed records without publishing; the saved publication preference and explicit restore/publish controls remain in Account’s secondary Nostr sync section. An actual local write failure raises the source storage warning until a successful retry. Provider failure retains the local collection.

The orb renderer uses the original eye arrays, palette material values and GLSL pigment fields translated to Metal, with the achievement collection’s wider camera/shadow frame rather than the compact Tutor frame. Award styles are opt-in parameters on the existing native sphere; Tutor and Conversation defaults retain their own visuals. Character reactions and the visual-only voice envelope use the original pure JavaScript policy through JavaScriptCore. Switching back to a Tutor orb restores its camera, material and default shader. Reduced Motion stops character and wave animation; backgrounding stops the renderer’s display link.
